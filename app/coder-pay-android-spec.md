# CP Watcher 安卓客户端编译与保活配置指南

由于 **CP Watcher** 是我们针对 Coder Pay 平台专门定制的到账监控 App，涉及系统底层的通知读取权限，因此**无法从任何公开应用商店（如 Google Play 或国内手机应用市场）下载**。它需要由您或您的团队利用我们已开发完毕的源码进行编译生成。

以下是获取安装包以及进行安卓真机测试的**保姆级详细步骤**：

---

## 第一阶段：如何编译并导出 Android App (APK)

因为是全新定制开发的挂机端，您需要使用 **Android Studio** 将源码打包成 `.apk` 文件安装到手机上。

### 步骤 1：准备开发环境
1. 确保您的电脑（或测试同事的电脑）上安装了 **Android Studio**（[前往官网下载安装](https://developer.android.com/studio)）。

### 步骤 2：导入并编译项目
1. 打开 Android Studio，点击 **`File -> Open`**。
2. 选择本地目录：**`coderpay-android`**（从您推送的 GitHub 仓库克隆的文件夹）。
3. 首次导入时，Android Studio 会在右下角自动下载 Gradle 依赖（这可能需要几分钟，请保持网络畅通）。

### 步骤 3：打包生成 APK
1. 等待项目构建（Build）成功、且下方无报错提示后。
2. 点击顶部菜单栏的 **`Build -> Build Bundle(s) / APK(s) -> Build APK(s)`**。
3. 编译完成后，Android Studio 右下角会弹出一个气泡提示，点击其中的 **`locate`** 链接。
4. 电脑文件夹会自动打开，您会看到一个名为 **`app-debug.apk`** 的文件。**这就是您的 CP Watcher 安装包！**

---

## 第二阶段：手机安装与关键权限配置

将打包出来的 `app-debug.apk` 发送到您的安卓手机并进行安装。安装后需要配置两个非常核心的“保活与监听权限”：

### 步骤 1：开启“通知栏读取权限”（拦截到账的核心）
1. 打开安装好的 **CP Watcher** App。
2. 在主界面“手机运行权限体检”一栏中，找到 **“通知栏读取监听权限”**，点击右侧黄色按钮 **“需授权”**。
3. 手机会自动跳转到系统的“设备和应用通知”设置页。
4. 在列表中找到 **`CP Watcher`**，打开其开关，并允许其访问通知。

### 步骤 2：忽略电池省电优化（防止系统杀后台）
1. 在 App 主界面，找到 **“电池省电限制忽略 (保活)”**，点击右侧黄色按钮 **“需设置”**。
2. 手机会弹出系统弹窗，询问是否允许该应用在后台运行且不限制电量，点击 **“允许”**。
3. *（推荐额外步骤）*：进入手机的系统设置 -> 找到“应用管理” -> `CP Watcher` -> 开启 **“自启动”** 和 **“无限制后台运行”**。

### 步骤 3：确认微信与支付宝通知设置
> [!WARNING]
> **非常重要**：确保您的微信和支付宝在系统通知管理中开启了 **“显示通知详情”**（如果设置为“隐藏通知内容”或“只显示收到一条消息”，App 将无法正则解析出具体金额）。

## 第三阶段：设备配对与全链路联调测试

### 步骤 1：云端获取配对码
1. 用电脑浏览器登录您的收银台后台控制台。
2. 进入 **“设备通道”**，添加一个新监控设备。
3. 系统会生成一个唯一的设备授权码，例如：`dev-1001`。

### 步骤 2：手机端绑定激活
1. 打开手机上的 **CP Watcher**。
2. 输入云端服务 URL：您部署的平台 API 地址（本地联调通常为 `http://IP:4000`）。
3. 输入设备授权码：`dev-1001`。
4. 点击 **“保存并连接探针”**。
5. 看到下方调试日志输出 `绑定成功！已拉起后台常驻保活，心跳正常建立。` 时，代表握手成功。此时在电脑端控制台查看该设备，状态应该已变为 **“在线”**。

### 步骤 3：发起首笔联调核销测试
1. **创建订单**：在控制台“沙箱测试”中创建一个 ¥0.01 的测试微信订单，浏览器会打开收银台收付款页面。
2. **本地模拟**：
   * 在手机 App 上，点击底部的绿色按钮 **“测试微信 ¥0.01”**。
   * **观察点 A（手机）**：控制台滚动打印拦截成功、正在计算签名、以及 WorkManager 上传成功日志。
   * **观察点 B（网页）**：电脑浏览器上的收银台订单页面会在 1 秒内自动感知到账并**自动跳转到成功页**。
3. **真实资金测试**（可选）：
   * 用另外一部手机扫描收银台上的微信/支付宝收款码，真实支付 ¥0.01。
   * 只要挂机手机的微信/支付宝弹出了系统通知栏提醒（如 `微信支付收款 0.01 元`），App 就会全自动核销，网页自动跳转。
